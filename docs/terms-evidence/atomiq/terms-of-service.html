2. What is the Atomiq Protocol

The Atomiq Protocol is a decentralized, permissionless and fully trustless cross-chain decentralized exchange (DEX). All transactions are processed atomically with strong security guarantees based on bitcoin light client (leveraging bitcoin's proof-of-work security) & submarine swaps (leveraging HTLCs - hash-time locked contracts over bitcoin's lightning network). With this approach the Atomiq Protocol is able to offer security guarantees far exceeding those of existing bridging or cross-chain swapping solutions. The Atomiq Protocol uses a network of Liquidity Provider nodes (LP) to process the swaps via a request for quote (RFQ) model. For more information, please see https://docs.atomiq.exchange.
