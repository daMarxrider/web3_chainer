Public API Portal — Available Networks

The Foundation’s public RPC at api.pocket.network provides free, keyless access to the blockchain networks listed below. No account, no API key, no rate-limit tiers to manage.

Rate limits:

  • 2,000 requests per IP per minute
  • 10,000 requests per second total per endpoint

Using an Endpoint

Every network is accessible at https://{chain-slug}.api.pocket.network:

bash
# Ethereum mainnet
curl -X POST https://eth.api.pocket.network \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":1}'

The slug is the service ID — see the table below for the full list.

Beyond Blockchains

The table above covers the public RPC. The network itself carries far more: any HTTP API can be a service, and most new services are data APIs, LLM inference, document tools, and MCP servers built for AI agents. Every registered service is listed at explorer.pocket.network/services, and the ones agents can pay to call are on the Agentic Portal.

Anyone can register a service permissionlessly. To publish your own, see Services.

Checking Status

  • Network analytics and relay data: analytics.pocket.network
  • On-chain service registry: explorer.pocket.network/services
  • On-chain query: pocketd query service all-services --network=main

Adding a New Chain to the Portal

If you’re a chain foundation wanting public portal coverage, see the F-Chains program or contact directors@pokt.foundation.
